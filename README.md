# GEN-IMAGE
### Model Details and Limitations

- Dataset: CelebA
- Architecture: Variational Autoencoder (VAE)
- Latent dimension: 200
- Input/output resolution: 32 × 32 RGB
- Training: 2 epochs

**Known limitations:** The current model is an experimental proof of concept. Due to limited training, the generated images may have low visual fidelity and may not preserve all facial details from the input image. Further training, higher-resolution inputs, and model improvements would be needed to improve output quality.
